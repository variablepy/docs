```http
POST https://api.hydrosolves.gay/admin/addBalance
```

Adds balance to an existing HydroSolve API key. Requires [admin authentication](/admin/overview#authentication).

## Request body

<ParamField body="key" type="string" required>
  The API key to credit.
</ParamField>

<ParamField body="amount" type="number" required>
  Number of solves to add to the key's balance.
</ParamField>

## Example

```bash
curl -X POST "https://api.hydrosolves.gay/admin/addBalance?admin_key=ADMIN_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "key": "EXISTING_API_KEY",
    "amount": 500
  }'
```

## Responses

### Success

```json
{
  "status": "success",
  "message": "Balance updated"
}
```

### Unauthorized

```http
HTTP/1.1 401
```

Returned when the request is missing a valid admin key.

### Key does not exist

```http
HTTP/1.1 404
```

Returned when the supplied `key` is not registered.
