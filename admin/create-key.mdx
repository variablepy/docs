```http
POST https://api.hydrosolves.gay/admin/createKey
```

Creates a new HydroSolve API key with an initial balance. Requires [admin authentication](/admin/overview#authentication).

## Request body

<ParamField body="key" type="string" required>
  The API key value to create.
</ParamField>

<ParamField body="balance" type="number" required>
  Initial balance to assign to the key, in solves.
</ParamField>

<ParamField body="email" type="string" required>
  Email address to associate with the key.
</ParamField>

## Example

```bash
curl -X POST "https://api.hydrosolves.gay/admin/createKey?admin_key=ADMIN_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "key": "NEW_API_KEY",
    "balance": 1000,
    "email": "customer@example.com"
  }'
```

## Responses

### Success

```json
{
  "status": "success",
  "message": "Key created"
}
```

### Duplicate key or email

```http
HTTP/1.1 409
```

Returned when the supplied `key` or `email` already exists. The response body describes which field conflicted.

### Unauthorized

```http
HTTP/1.1 401
```

Returned when the request is missing a valid admin key.
