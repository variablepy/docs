The Admin API is used to manage API keys and balances directly. These endpoints are **admin-only** and are not available to regular API users.

<Warning>
  Admin endpoints require the HydroSolve admin key. Do not expose the admin key in client-side code, logs, or version control.
</Warning>

## Authentication

All admin endpoints accept the admin key through any of the following:

- Query parameter: `?admin_key=...` or `?adminkey=...`
- HTTP header: `admin_key: ...` or `adminkey: ...`
- JSON body: `{ "admin_key": "..." }` or `{ "adminkey": "..." }`

Both `admin_key` and `adminkey` are accepted interchangeably.
