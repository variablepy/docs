# Authentication

All requests require an API key passed in the JSON body as `key`.

```json
{
  "key": "hydrosolves-xxxxxxxx",
  "type": "HCaptchaCaptchaToken",
  "task": { ... }
}
```

Alternative field names `apikey` and `clientKey` are also accepted.

Keys are issued by the admin. Each key has a prepaid balance. Tasks deduct from your balance on creation.

## Balance Check

```bash
curl -X POST https://api.hydrosolves.gay/getBalance \
  -H "Content-Type: application/json" \
  -d '{"key": "hydrosolves-xxxxxxxx"}'
```

Returns:

```json
{ "status": "success", "balance": "$15.00" }
```
