---
title: "Create Task"
description: "Submit an asynchronous captcha-solving task."
---

```http
POST https://api.hydrosolves.gay/createTask
```

Creates an asynchronous solving task and returns a `task_id` you can poll with [`/getResult/{task_id}`](/endpoints/get-result).

## Request body

### API key

<ParamField body="key" type="string" required>
  Your HydroSolve API key. `clientKey` is accepted as an alias.
</ParamField>

### Task type

<ParamField body="type" default="HCaptchaCaptchaToken" type="string">
  The task type to run. `tasktype` is accepted as an alias.

  Supported values:

  - `HCaptchaCaptchaToken`
  - `HCaptchaEnterpriseToken`
  - `TurnstileCaptcha`
  - `TurnstileCaptchaProxyless`
</ParamField>

### Task parameters

<ParamField body="task" type="object" required>
  The task parameters. `data` is accepted as an alias for the task object.

  <Expandable title="task properties">
    <ParamField body="sitekey" type="string" required>
      The target site's captcha sitekey. `websiteKey` is accepted as an alias.
    </ParamField>

    <ParamField body="siteurl" type="string" required>
      The full URL of the page hosting the captcha. `websiteURL` is accepted as an alias.
    </ParamField>

    <ParamField body="proxy" type="string">
      Upstream proxy in `scheme://user:pass@host:port` format. Required for `HCaptchaCaptchaToken`, `HCaptchaEnterpriseToken`, and `TurnstileCaptcha`. Not required for `TurnstileCaptchaProxyless`.
    </ParamField>

    <ParamField body="user_agent" type="string">
      Browser user-agent string. Required for hCaptcha tasks. Accepted but not required for Turnstile. Aliases: `useragent`, `userAgent`.
    </ParamField>

    <ParamField body="rqdata" type="string">
      hCaptcha `rqdata` value, when required by the target site. Alias: `data` (when the outer task object is not itself named `data`). Supplying `rqdata` increases the create-task balance deduction to `1.0`.
    </ParamField>

    <ParamField body="pageaction" type="string">
      Turnstile `pageaction`. Alias: `pageAction`.
    </ParamField>

    <ParamField body="data" type="string">
      Turnstile `data` value.
    </ParamField>

    <ParamField body="pagedata" type="string">
      Turnstile `pagedata`. Aliases: `pageData`, `chlPageData`.
    </ParamField>
  </Expandable>
</ParamField>

## Field aliases

The API accepts multiple aliases for common fields so it can slot in as a drop-in replacement for other solvers.

| Field | Aliases |
| --- | --- |
| API key | `key`, `clientKey` |
| Task type | `type`, `tasktype` |
| Task object | `task`, `data` |
| Sitekey | `sitekey`, `websiteKey` |
| Site URL | `siteurl`, `websiteURL` |
| rqdata | `rqdata`, `data` |
| User agent | `user_agent`, `useragent`, `userAgent` |
| pageaction | `pageaction`, `pageAction` |
| pagedata | `pagedata`, `pageData`, `chlPageData` |

## Canonical hCaptcha request

```json
{
  "key": "YOUR_API_KEY",
  "type": "HCaptchaCaptchaToken",
  "task": {
    "sitekey": "HCAPTCHA_SITEKEY",
    "siteurl": "https://example.com",
    "rqdata": "",
    "proxy": "http://username:password@host:port",
    "user_agent": "Mozilla/5.0 ..."
  }
}
```

## Response

A successful submission returns HTTP `200` with:

```json
{
  "status": "queued",
  "task_id": "TASK_ID"
}
```

The task has been accepted and placed into the solving queue. Poll [`/getResult/{task_id}`](/endpoints/get-result) to retrieve the token.
