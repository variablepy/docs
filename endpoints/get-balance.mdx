# Get Balance

`POST /getBalance`

Returns your current account balance.

## Request Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `key` | string | Yes | Your API key |

## Response

```json
{
  "status": "success",
  "balance": "$15.00"
}
```
