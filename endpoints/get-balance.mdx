# Get Balance

`GET /getBalance?apikey=<key>`

Returns your current account balance.

## Query Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `apikey` | string | Yes | Your API key |

## Response

```json
{
  "status": "success",
  "balance": 10.0
}
```
