---
title: "Get Balance"
description: "Retrieve your remaining HydroSolve balance."
---

```http
POST https://api.hydrosolves.gay/getBalance
```

Returns your remaining HydroSolve balance as a USD-formatted string.

## Request body

<ParamField body="key" type="string" required>
  Your HydroSolve API key.
</ParamField>

## Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrosolves.gay/getBalance \
  -H "Content-Type: application/json" \
  -d '{ "key": "YOUR_API_KEY" }'
```

```python Python
import requests

res = requests.post(
    "https://api.hydrosolves.gay/getBalance",
    json={"key": "YOUR_API_KEY"},
)
print(res.json())
```

```javascript JavaScript
const res = await fetch("https://api.hydrosolves.gay/getBalance", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ key: "YOUR_API_KEY" }),
});
console.log(await res.json());
```

</CodeGroup>

## Response

```json
{
  "status": "success",
  "balance": "$1.50"
}
```

The `balance` field is a USD-formatted string. HydroSolve stores balance in solves and converts to USD using `1 solve = $0.0015`.

## Errors

| HTTP | Response | When it happens |
| --- | --- | --- |
| 400 | `{ "status": "error", "message": "Missing API key" }` | Request body has no `key`. |
| 403 | `{ "status": "error", "message": "Invalid API key" }` | The supplied key is invalid. |
