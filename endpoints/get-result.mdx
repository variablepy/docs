# Get Result

`GET /getResult`

Poll this endpoint until the status changes from `solving` to `solved` or `failed`.

## Query Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `task_id` | string | Yes | Task ID from createTask response |

You can also use `taskId`, `taskid`, or pass `task_id` in a POST body.

## Response — Solving

```json
{ "status": "solving" }
```

## Response — Solved

```json
{
  "status": "solved",
  "cost": "$0.00150",
  "solution": {
    "token": "P0_eyJ2IjoiMi...",
    "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
  }
}
```

## Response — Failed

```json
{
  "status": "failed",
  "errorId": 1,
  "error": "SOLVE_TIMEOUT"
}
```

## Result Retention

Results are stored for 5 minutes after solving. After that, they are cleaned up.
