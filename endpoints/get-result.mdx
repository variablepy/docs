# Get Result

`GET /getResult`

Poll this endpoint until the status changes from `solving` to `solved` or `failed`.

## Query Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `task_id` | string | Yes | Task ID from createTask response |

You can also use `taskId`, `taskid`, or pass `task_id` in a POST body.

## Response — Solving

```json
{ "status": "solving" }
```

## Response — Solved

```json
{
  "status": "solved",
  "cost": "$0.00150",
  "solution": {
    "token": "P0_eyJ2IjoiMi...",
    "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
  }
}
```

## Response — Failed

```json
{
  "status": "failed",
  "errorId": 1,
  "error": "SOLVE_TIMEOUT"
}
```

## Type-Specific Fields

Most task types return `token` and `user_agent`. A few add fields the target expects:

| Task type | Additional solution fields |
| --- | --- |
| `CloudflareJsdCookie` | `cookies` instead of `token` |
| `KasadaCtToken` | `cookies`, `headers` |
| `TurnstileCaptcha`, `TurnstileCaptchaProxyless` | `supressed` |
| `LeminToken`, `LeminTokenProxyLess` | `challenge_id` — submit it alongside the token as `lemin_challenge_id` |
| `AkamaiCookie` | `cookies` instead of `token` |
| `FuncaptchaToken` | `token`, plus `suppressed` and `user_agent` |

## Result Retention

Results are stored for 5 minutes after solving. After that, they are cleaned up.
