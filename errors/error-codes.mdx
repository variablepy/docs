# Error Code Reference

When a task fails, the response includes an error string.

## Solver Errors

| Error | Description |
| --- | --- |
| `SOLVE_FAILED` | Generic solve failure |
| `SOLVE_TIMEOUT` | Task exceeded the time limit |
| `EMPTY_TOKEN` | Solver returned an empty token |
| `MAX_ROUNDS` | Exceeded maximum retry rounds |
| `EMPTY_RESPONSE` | Empty response from solver |
| `BAD_RESPONSE` | Bad or malformed response |
| `NO_CHALLENGE` | No challenge found |

## Connection Errors

| Error | Description |
| --- | --- |
| `PROXY_ERROR` | Proxy connection failed |
| `PROXY_LIMITED` | Proxy rate-limited |
| `NETWORK_ERROR` | Network/SSL/TLS connection error |
| `BROWSER_FAILED` | Browser initialization failed |
| `HTTPCLOAK_MISSING` | httpcloak dependency not installed |

## API Errors

| Error | Description |
| --- | --- |
| `BAD_REQUEST` | Missing required parameters |
| `NO_COOKIE` | No cookie/token was obtained |
| `BAD_TASK_TYPE` | Unknown task type |

## hCaptcha Specific

| Error | Description |
| --- | --- |
| `HSW_FAILED` | hCaptcha HSW challenge failed |
| `CAPTCHA_FAILED` | Captcha recognition failed |
| `CLICK_FAILED` | Click interaction failed |
| `SITE_CONFIG_FAILED` | Failed to load site config |

## reCAPTCHA v3 Specific

| Error | Description |
| --- | --- |
| `ANCHOR_FAILED` | reCAPTCHA anchor request failed |
| `RELOAD_FAILED` | reCAPTCHA reload request failed |
| `TOKEN_PARSE_FAILED` | Failed to parse reCAPTCHA token from response |
| `VERSION_RESOLVE_FAILED` | Failed to resolve reCAPTCHA version |
| `FINGERPRINT_FAILED` | Failed to generate fingerprint |
| `RECAPTCHA_V3_FAILED` | Generic reCAPTCHA v3 solve failure |
