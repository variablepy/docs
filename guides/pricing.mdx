# Pricing

Each task type has a fixed per-solve price. Charges are deducted from your account balance when a task is created.

hCaptcha is priced per proof-of-work engine, selected with the `pow_type` task parameter. When `pow_type` is omitted, `HCaptchaCaptchaToken` runs on `hsl` and `HCaptchaEnterpriseToken` runs on `hsw`, so those are the default rows below.

## How Charging Works

1. You submit a task via `/createTask`
2. Your balance is deducted immediately
3. If the task **fails**, your balance is **automatically refunded**

## Check Balance

```bash
curl -X POST https://api.hydrosolves.gay/getBalance \
  -H "Content-Type: application/json" \
  -d '{"key": "hydrosolves-xxxxxxxx"}'
```
