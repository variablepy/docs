# Pricing

Each task type has a fixed per-solve price. Charges are deducted from your account balance when a task is created.

## Prices

| Task Type | Solves / Task | Price / Task |
| --- | --- | --- |
| `HCaptchaCaptchaToken` | 1 | \$0.0015 |
| `HCaptchaEnterpriseToken` | 4 | \$0.006 |
| `TurnstileCaptcha` | 1 | \$0.0015 |
| `TurnstileCaptchaProxyless` | 1 | \$0.0015 |
| `CloudflareJsdCookie` | 1 | \$0.0015 |
| `AWSWafToken` | 1 | \$0.0015 |
| `AWSWafTokenProxyless` | 1 | \$0.0015 |
| `KasadaCtToken` | 1 | \$0.0015 |
| `DataDomeTagsCookie` | 1 | \$0.0015 |
| `ReCaptchaV3Token` | 1 | \$0.0015 |
| `ReCaptchaV3TokenProxyLess` | 1 | \$0.0015 |
| `ReCaptchaV3EnterpriseToken` | 4 | \$0.006 |
| `ReCaptchaV3EnterpriseTokenProxyLess` | 4 | \$0.006 |

## How Charging Works

1. You submit a task via `/createTask`
2. Your balance is deducted immediately
3. If the task fails, the charge is **not** refunded

## Check Balance

```bash
curl -X POST https://api.hydrosolves.gay/getBalance \
  -H "Content-Type: application/json" \
  -d '{"key": "hydrosolves-xxxxxxxx"}'
```
