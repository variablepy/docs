# Pricing

Each task type has a fixed per-solve price. Charges are deducted from your account balance when a task is created.

## Prices

| Task Type | Price / 1k Solves |
| --- | --- |
| `HCaptchaCaptchaToken` | \$1.50 |
| `HCaptchaEnterpriseToken` | \$2.00 |
| `TurnstileCaptcha` | \$0.09 |
| `TurnstileCaptchaProxyless` | \$0.09 |
| `CloudflareJsdCookie` | \$0.20 |
| `AWSWafToken` | \$0.40 |
| `AWSWafTokenProxyless` | \$0.40 |
| `KasadaCtToken` | \$0.80 |
| `DataDomeTagsCookie` | \$0.80 |
| `ReCaptchaV3Token` | \$0.50 |
| `ReCaptchaV3TokenProxyLess` | \$0.50 |
| `ReCaptchaV3EnterpriseToken` | \$0.50 |
| `ReCaptchaV3EnterpriseTokenProxyLess` | \$0.50 |

## How Charging Works

1. You submit a task via `/createTask`
2. Your balance is deducted immediately
3. If the task fails, the charge is **not** refunded

## Check Balance

```bash
curl -X POST https://api.hydrosolves.gay/getBalance \
  -H "Content-Type: application/json" \
  -d '{"key": "hydrosolves-xxxxxxxx"}'
```
