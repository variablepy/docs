# HydroSolve

Fast, reliable captcha-solving API. Submit a task, poll for results, get a token.

## Base URL

```text
https://api.hydrosolves.gay
```

## Supported Task Types

| Task Type | Price / Solve |
| --- | --- |
| `HCaptchaCaptchaToken` | 1 solve (\$0.0015) |
| `HCaptchaEnterpriseToken` | 4 solves (\$0.006) |
| `TurnstileCaptcha` | 1 solve (\$0.0015) |
| `TurnstileCaptchaProxyless` | 1 solve (\$0.0015) |
| `CloudflareJsdCookie` | 1 solve (\$0.0015) |
| `AWSWafToken` | 1 solve (\$0.0015) |
| `AWSWafTokenProxyless` | 1 solve (\$0.0015) |
| `KasadaCtToken` | 1 solve (\$0.0015) |
| `DataDomeTagsCookie` | 1 solve (\$0.0015) |
| `ReCaptchaV3Token` | 1 solve (\$0.0015) |
| `ReCaptchaV3TokenProxyLess` | 1 solve (\$0.0015) |
| `ReCaptchaV3EnterpriseToken` | 4 solves (\$0.006) |
| `ReCaptchaV3EnterpriseTokenProxyLess` | 4 solves (\$0.006) |

## Quick Example

```bash
curl -X POST https://api.hydrosolves.gay/createTask \
  -H "Content-Type: application/json" \
  -d '{
    "key": "hydrosolves-xxxxxxxx",
    "type": "HCaptchaCaptchaToken",
    "task": {
      "sitekey": "10000000-ffff-ffff-ffff-000000000001",
      "siteurl": "https://example.com",
      "proxy": "http://user:pass@host:port",
      "user_agent": "Mozilla/5.0 ..."
    }
  }'
```

## How It Works

1. **Create a task** — `POST /createTask` with the task type and parameters
2. **Poll for result** — `GET /getResult?task_id=<id>`
3. **Use the token** — inject the solved token into your site

Most solves complete in under 60 seconds. DataDome solves in under 1 second.
