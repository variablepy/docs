HydroSolve is a developer API that solves anti-bot challenges programmatically. Submit a task, poll for the result, and receive a solved token you can use in your automation.

## How it works

The API is asynchronous. Every solve follows the same five steps:

<Steps>
  <Step title="Submit a task">
    `POST` to [`/createTask`](/endpoints/create-task) with your API key and target challenge.
  </Step>
  <Step title="Receive a task ID">
    The API returns a `task_id` and queues the task.
  </Step>
  <Step title="Poll for the result">
    `GET` [`/getResult/{task_id}`](/endpoints/get-result) until `status` is `solved` or `failed`.
  </Step>
  <Step title="Use the token">
    Read the token from `solution.token` and submit it to the target site.
  </Step>
  <Step title="Check your balance">
    `POST` to [`/getBalance`](/endpoints/get-balance) at any time to see remaining balance.
  </Step>
</Steps>

## Base URL

All endpoints are served from a single base URL:

```text
https://api.hydrosolves.gay
```
