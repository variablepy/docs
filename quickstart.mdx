# Getting Started

## 1. Get Your API Key

Contact the admin to receive your API key. Keys start with `hydrosolves-`.

## 2. Create a Task

```bash
curl -X POST https://api.hydrosolves.gay/createTask \
  -H "Content-Type: application/json" \
  -d '{
    "key": "hydrosolves-xxxxxxxx",
    "type": "HCaptchaCaptchaToken",
    "task": {
      "sitekey": "10000000-ffff-ffff-ffff-000000000001",
      "siteurl": "https://example.com",
      "proxy": "http://user:pass@host:port",
      "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
    }
  }'
```

Response:

```json
{ "status": "queued", "task_id": "1722000000000" }
```

## 3. Poll for Result

```bash
curl "https://api.hydrosolves.gay/getResult?task_id=1722000000000"
```

When solved:

```json
{
  "status": "solved",
  "cost": "$0.00150",
  "solution": {
    "token": "P0_eyJ2IjoiMi...",
    "user_agent": "Mozilla/5.0 ..."
  }
}
```

When still solving:

```json
{ "status": "solving" }
```

## 4. Check Balance

```bash
curl -X POST https://api.hydrosolves.gay/getBalance \
  -H "Content-Type: application/json" \
  -d '{"key": "hydrosolves-xxxxxxxx"}'
```
