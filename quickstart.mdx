This guide walks you through your first HydroSolve solve, from getting an API key to reading the solved token.

## 1. Get an API key

Purchase an API key from the official HydroSolve store:

<Card title="Get an API Key" icon="key" href="https://hydrosolves.mysellauth.com/">
  Buy a HydroSolve API key at `hydrosolves.mysellauth.com`.
</Card>

Keep this key private. Anyone with your key can spend your balance.

## 2. Learn the base URL

All requests target a single base URL. Every example in this documentation uses it directly.

```text
https://api.hydrosolves.gay
```

Every endpoint accepts and returns JSON. Set `Content-Type: application/json` on every request that has a body.

## 3. Submit a task

Send a `POST` request to `/createTask` with your API key and challenge parameters.

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrosolves.gay/createTask \
  -H "Content-Type: application/json" \
  -d '{
    "key": "YOUR_API_KEY",
    "type": "HCaptchaCaptchaToken",
    "task": {
      "sitekey": "HCAPTCHA_SITEKEY",
      "siteurl": "https://example.com",
      "proxy": "http://username:password@host:port",
      "user_agent": "Mozilla/5.0 ..."
    }
  }'
```

```python Python
import requests

r = requests.post(
    "https://api.hydrosolves.gay/createTask",
    json={
        "key": "YOUR_API_KEY",
        "type": "HCaptchaCaptchaToken",
        "task": {
            "sitekey": "HCAPTCHA_SITEKEY",
            "siteurl": "https://example.com",
            "proxy": "http://username:password@host:port",
            "user_agent": "Mozilla/5.0 ...",
        },
    },
)
task_id = r.json()["task_id"]
```

```javascript JavaScript
const res = await fetch("https://api.hydrosolves.gay/createTask", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    key: "YOUR_API_KEY",
    type: "HCaptchaCaptchaToken",
    task: {
      sitekey: "HCAPTCHA_SITEKEY",
      siteurl: "https://example.com",
      proxy: "http://username:password@host:port",
      user_agent: "Mozilla/5.0 ...",
    },
  }),
});
const { task_id } = await res.json();
```

</CodeGroup>

A successful submission returns:

```json
{
  "status": "queued",
  "task_id": "TASK_ID"
}
```

## 4. Poll for the result

Call `/getResult/{task_id}` until `status` becomes `solved` or `failed`. While the task is still processing, the response is:

```json
{
  "status": "solving"
}
```

<CodeGroup>

```bash cURL
curl https://api.hydrosolves.gay/getResult/TASK_ID
```

```python Python
import time, requests

while True:
    r = requests.get(f"https://api.hydrosolves.gay/getResult/{task_id}").json()
    if r["status"] in ("solved", "failed"):
        break
    time.sleep(2)

print(r)
```

```javascript JavaScript
let result;
while (true) {
  const r = await fetch(`https://api.hydrosolves.gay/getResult/${task_id}`);
  result = await r.json();
  if (result.status === "solved" || result.status === "failed") break;
  await new Promise((r) => setTimeout(r, 2000));
}
console.log(result);
```

</CodeGroup>

A solved response includes the token:

```json
{
  "status": "solved",
  "cost": "$0.00075",
  "solution": {
    "token": "HCAPTCHA_TOKEN",
    "supressed": false
  }
}
```

<Note>
  Task results are retained for approximately **300 seconds**. Poll and retrieve promptly.
</Note>

## 5. Check your balance

At any time, `POST` to `/getBalance` with your API key:

```bash
curl -X POST https://api.hydrosolves.gay/getBalance \
  -H "Content-Type: application/json" \
  -d '{ "key": "YOUR_API_KEY" }'
```

```json
{
  "status": "success",
  "balance": "$1.50"
}
```
