---
title: "AWS WAF Proxyless"
description: "Solve AWS WAF challenges without a proxy."
---

`AWSWafTokenProxyless` solves AWS WAF challenges without requiring you to supply a proxy.

## Requirements

| Field | Required |
| --- | --- |
| API key | Yes |
| `siteurl` | Yes |
| `proxy` | Not required |
| `user_agent` | Optional (accepted but not required) |

All [AWS WAF task parameters](/task-types/aws-waf#aws-waf-task-parameters) (`awsKey`, `awsIv`, `awsContext`, `awsChallengeJS`, `awsApiJs`, `awsProblemUrl`, `awsApiKey`, `awsExistingToken`) are accepted here in the same JSON casing.

## Request

```json
{
  "key": "YOUR_API_KEY",
  "type": "AWSWafTokenProxyless",
  "task": {
    "siteurl": "https://example.com"
  }
}
```

## Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrosolves.gay/createTask \
  -H "Content-Type: application/json" \
  -d '{
    "key": "YOUR_API_KEY",
    "type": "AWSWafTokenProxyless",
    "task": {
      "siteurl": "https://example.com"
    }
  }'
```

```python Python
import requests

res = requests.post(
    "https://api.hydrosolves.gay/createTask",
    json={
        "key": "YOUR_API_KEY",
        "type": "AWSWafTokenProxyless",
        "task": {"siteurl": "https://example.com"},
    },
)
print(res.json())
```

```javascript JavaScript
const res = await fetch("https://api.hydrosolves.gay/createTask", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    key: "YOUR_API_KEY",
    type: "AWSWafTokenProxyless",
    task: { siteurl: "https://example.com" },
  }),
});
console.log(await res.json());
```
