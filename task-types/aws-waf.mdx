---
title: "AWS WAF"
description: "Solve AWS WAF challenges through your proxy."
---

`AWSWafToken` solves AWS WAF challenges using a proxy you supply.

## Requirements

| Field | Required |
| --- | --- |
| API key | Yes |
| `siteurl` | Yes |
| `proxy` | Yes |
| `user_agent` | Optional (accepted but not required) |

<Note>
  AWS WAF does not require `sitekey`. Use `siteurl` and the AWS WAF-specific challenge parameters below.
</Note>

## AWS WAF task parameters

Supply these fields inside the `task` object when the target challenge requires them. Use the exact JSON casing shown.

| Field | Description |
| --- | --- |
| `awsKey` | AWS WAF challenge key. |
| `awsIv` | AWS WAF initialization vector. |
| `awsContext` | AWS WAF challenge context. |
| `awsChallengeJS` | URL of the AWS WAF challenge JavaScript. |
| `awsApiJs` | URL of the AWS WAF API JavaScript. |
| `awsProblemUrl` | AWS WAF problem URL. |
| `awsApiKey` | AWS WAF API key from the challenge page. |
| `awsExistingToken` | Existing AWS WAF token, when refreshing. |

## Request

```json
{
  "key": "YOUR_API_KEY",
  "type": "AWSWafToken",
  "task": {
    "siteurl": "https://example.com",
    "proxy": "http://username:password@host:port",
    "user_agent": "Mozilla/5.0 ...",
    "awsKey": "AWS_KEY",
    "awsIv": "AWS_IV",
    "awsContext": "AWS_CONTEXT",
    "awsChallengeJS": "https://.../challenge.js",
    "awsApiJs": "https://.../api.js",
    "awsProblemUrl": "https://.../problem",
    "awsApiKey": "AWS_API_KEY"
  }
}
```

## Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrosolves.gay/createTask \
  -H "Content-Type: application/json" \
  -d '{
    "key": "YOUR_API_KEY",
    "type": "AWSWafToken",
    "task": {
      "siteurl": "https://example.com",
      "proxy": "http://username:password@host:port"
    }
  }'
```

```python Python
import requests

res = requests.post(
    "https://api.hydrosolves.gay/createTask",
    json={
        "key": "YOUR_API_KEY",
        "type": "AWSWafToken",
        "task": {
            "siteurl": "https://example.com",
            "proxy": "http://username:password@host:port",
        },
    },
)
print(res.json())
```

```javascript JavaScript
const res = await fetch("https://api.hydrosolves.gay/createTask", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    key: "YOUR_API_KEY",
    type: "AWSWafToken",
    task: {
      siteurl: "https://example.com",
      proxy: "http://username:password@host:port",
    },
  }),
});
console.log(await res.json());
```
