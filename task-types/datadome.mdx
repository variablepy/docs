---
title: "DataDome"
description: "Solve DataDome challenges and retrieve the DataDome cookie."
---

`DataDomeTagsCookie` solves DataDome challenges and returns the DataDome cookie token. The solver internally uses the DataDome tags solver.

## Requirements

| Field | Required |
| --- | --- |
| API key | Yes |
| `siteurl` | Yes |
| `sitekey` | Yes |
| `proxy` | Yes |
| `user_agent` | Yes |

<Note>
  For `DataDomeTagsCookie`, the `sitekey` field carries the DataDome JS URL (the DDJS key input) required by the tags solver.
</Note>

## Request

```json
{
  "key": "YOUR_API_KEY",
  "type": "DataDomeTagsCookie",
  "task": {
    "siteurl": "https://example.com",
    "sitekey": "https://ct.datadome.co/.../tags.js",
    "proxy": "http://username:password@host:port",
    "user_agent": "Mozilla/5.0 ..."
  }
}
```
