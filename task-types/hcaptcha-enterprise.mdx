---
title: "hCaptcha Enterprise"
description: "Solve hCaptcha Enterprise challenges."
---

`HCaptchaEnterpriseToken` solves hCaptcha Enterprise challenges. It uses the same request shape as [`HCaptchaCaptchaToken`](/task-types/hcaptcha).

## Requirements

| Field | Required |
| --- | --- |
| API key | Yes |
| `sitekey` | Yes |
| `siteurl` | Yes |
| `proxy` | Yes |
| `user_agent` | Yes |
| `rqdata` | Optional |

<Note>
  Enterprise tasks consume `1.0` balance when the task is created, per the current API charge logic.
</Note>

## Request

```json
{
  "key": "YOUR_API_KEY",
  "type": "HCaptchaEnterpriseToken",
  "task": {
    "sitekey": "HCAPTCHA_SITEKEY",
    "siteurl": "https://example.com",
    "proxy": "http://username:password@host:port",
    "user_agent": "Mozilla/5.0 ..."
  }
}
```
