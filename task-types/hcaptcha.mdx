`HCaptchaCaptchaToken` is the default task type. Use it to solve standard hCaptcha challenges.

## Requirements

| Field | Required |
| --- | --- |
| API key | Yes |
| `sitekey` | Yes |
| `siteurl` | Yes |
| `proxy` | Yes |
| `user_agent` | Yes |
| `rqdata` | Optional |

The API rejects hCaptcha tasks without a proxy or without a user agent.

## Request

```json
{
  "key": "YOUR_API_KEY",
  "type": "HCaptchaCaptchaToken",
  "task": {
    "sitekey": "HCAPTCHA_SITEKEY",
    "siteurl": "https://example.com",
    "rqdata": "",
    "proxy": "http://username:password@host:port",
    "user_agent": "Mozilla/5.0 ..."
  }
}
```

## With rqdata

Supply `rqdata` when the target hCaptcha requires it. Providing `rqdata` changes the create-task balance deduction to `1.0`.

```json
{
  "key": "YOUR_API_KEY",
  "type": "HCaptchaCaptchaToken",
  "task": {
    "sitekey": "HCAPTCHA_SITEKEY",
    "siteurl": "https://example.com",
    "rqdata": "RQDATA_VALUE",
    "proxy": "http://username:password@host:port",
    "user_agent": "Mozilla/5.0 ..."
  }
}
```

## Successful result

```json
{
  "status": "solved",
  "cost": "$0.00075",
  "solution": {
    "token": "HCAPTCHA_TOKEN",
    "supressed": false
  }
}
```

The reported `cost` is `$0.00075`. See [Pricing](/guides/pricing) for how balance deduction relates to `cost`.
