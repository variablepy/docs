# hCaptcha

Solve hCaptcha and hCaptcha Enterprise challenges and receive a verification token.

## Task Types

- `HCaptchaCaptchaToken` — standard hCaptcha, solved with the `hsl` proof of work by default
- `HCaptchaEnterpriseToken` — hCaptcha Enterprise, solved with the `hsw` proof of work by default

Both types accept the same parameters. The proof-of-work engine can be overridden per task with `pow_type`.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `sitekey` | string | Yes | hCaptcha site key |
| `siteurl` | string | Yes | Page URL with the captcha |
| `proxy` | string | Yes | `http://user:pass@host:port` |
| `user_agent` | string | Yes | Browser user agent |
| `rqdata` | string | No | Request data from the page |
| `pow_type` | string | No | `hsl` or `hsw`. Defaults to `hsl` on `HCaptchaCaptchaToken` and `hsw` on `HCaptchaEnterpriseToken` |

## Proof Of Work

| `pow_type` | Engine | Notes |
| --- | --- | --- |
| `hsl` | Native SHA-1 proof of work | Fast and low overhead |
| `hsw` | WASM proof of work | Required by enterprise sitekeys |

`hsl` is the default for standard tasks and is the cheaper engine. Set `pow_type` to `hsw` only when a target demands the enterprise proof. Pricing per engine is listed below.

## Request — Standard

```json
{
  "type": "HCaptchaCaptchaToken",
  "task": {
    "sitekey": "10000000-ffff-ffff-ffff-000000000001",
    "siteurl": "https://example.com/login",
    "proxy": "http://user:pass@host:port",
    "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/136.0.0.0 Safari/537.36",
    "pow_type": "hsl"
  }
}
```

## Request — Enterprise


| --- | --- | --- |

| `HCaptchaEnterpriseToken` | `hsl` | \$0.40 |
| `HCaptchaEnterpriseToken` | `hsw` | \$2.00 |

## Response Token

The `token` field contains the `P0_eyJ...` hCaptcha verification token.
