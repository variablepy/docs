# Lemin

Solve Lemin cropped puzzles and receive the answer payload plus the pre-validation token Lemin expects on its server-side validation call.

## Task Types

- `LeminToken` — requires a proxy
- `LeminTokenProxyLess` — solved without a proxy, from our own egress

Both types accept the same parameters and return the same solution.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `siteurl` | string | Yes | Page URL hosting the widget, e.g. `https://example.com/login` |
| `captcha_id` | string | Yes | Captcha key from the widget script URL, e.g. `CROPPED_b6fb18a_eb49f27e803e4f59af232e0b5d826ad4` |
| `div_id` | string | Yes | Id of the container element the widget is mounted in, e.g. `lemin-cropped-captcha` |
| `proxy` | string | Yes for `LeminToken` | `http://user:pass@host:port` |
| `user_agent` | string | No | User agent to solve with, defaults to our Firefox profile |
| `lemin_subdomain` | string | No | API subdomain override, defaults to `api` (`https://api.leminnow.com`) |

## Finding Your Parameters

Both values come from the page that loads the widget:

```html
<div id="lemin-cropped-captcha"></div>
<script src="https://api.leminnow.com/captcha/v1/cropped/CROPPED_b6fb18a_eb49f27e803e4f59af232e0b5d826ad4/js"></script>
```

- `captcha_id` is the path segment before `/js`
- `div_id` is the id of the div the script is placed in

## Request

```json
{
  "type": "LeminToken",
  "task": {
    "siteurl": "https://example.com/login",
    "captcha_id": "CROPPED_b6fb18a_eb49f27e803e4f59af232e0b5d826ad4",
    "div_id": "lemin-cropped-captcha",
    "proxy": "http://user:pass@host:port"
  }
}
```

## Solution

| Field | Description |
| --- | --- |
| `token` | The `lemin_answer` value to submit with your form: the drag trajectory with the pre-validation token appended (`<trajectory>_?_gAAAAAB...`) |
| `challenge_id` | The challenge the token belongs to — submit it as `lemin_challenge_id` |
| `user_agent` | User agent the solve was performed with, reuse it for the submission |

```json
{
  "status": "solved",
  "cost": "$0.00100",
  "solution": {
    "token": "0xaxcgx0x0xc6x0x0bix..._?_gAAAAABqqPxV...",
    "challenge_id": "b5db51e4-b4e1-4f98-9823-e1764457339b",
    "user_agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:155.0) Gecko/20100101 Firefox/155.0"
  }
}
```

Lemin validates on the server side, so both values are needed: hand them to your backend as `lemin_challenge_id` and `lemin_answer`, and let it call Lemin's `/captcha/v1/cropped/validate` with your private key.
