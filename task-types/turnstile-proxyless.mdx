---
title: "Turnstile Proxyless"
description: "Solve Cloudflare Turnstile without a proxy."
---

`TurnstileCaptchaProxyless` solves Cloudflare Turnstile challenges without requiring you to supply a proxy.

## Requirements

| Field | Required |
| --- | --- |
| API key | Yes |
| `sitekey` | Yes |
| `siteurl` | Yes |
| `proxy` | Not required |
| `user_agent` | Optional (accepted but not required) |
| `pageaction` | Optional |
| `data` | Optional |
| `pagedata` | Optional |

<Note>
  The [Missing proxy](/errors/create-task-errors) error does **not** apply to `TurnstileCaptchaProxyless`.
</Note>

## Request

```json
{
  "key": "YOUR_API_KEY",
  "type": "TurnstileCaptchaProxyless",
  "task": {
    "sitekey": "TURNSTILE_SITEKEY",
    "siteurl": "https://example.com",
    "pageaction": "",
    "data": "",
    "pagedata": ""
  }
}
```

## Examples

<CodeGroup>

```bash cURL
curl -X POST https://api.hydrosolves.gay/createTask \
  -H "Content-Type: application/json" \
  -d '{
    "key": "YOUR_API_KEY",
    "type": "TurnstileCaptchaProxyless",
    "task": {
      "sitekey": "TURNSTILE_SITEKEY",
      "siteurl": "https://example.com"
    }
  }'
```

```python Python
import requests

res = requests.post(
    "https://api.hydrosolves.gay/createTask",
    json={
        "key": "YOUR_API_KEY",
        "type": "TurnstileCaptchaProxyless",
        "task": {
            "sitekey": "TURNSTILE_SITEKEY",
            "siteurl": "https://example.com",
        },
    },
)
print(res.json())
```

```javascript JavaScript
const res = await fetch("https://api.hydrosolves.gay/createTask", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    key: "YOUR_API_KEY",
    type: "TurnstileCaptchaProxyless",
    task: {
      sitekey: "TURNSTILE_SITEKEY",
      siteurl: "https://example.com",
    },
  }),
});
console.log(await res.json());
```
