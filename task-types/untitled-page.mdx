# reCAPTCHA v3

Solve reCAPTCHA v3 and reCAPTCHA v3 Enterprise challenges and receive a verification token.

## Task Types

- `ReCaptchaV3Token` — standard reCAPTCHA v3
- `ReCaptchaV3TokenProxyLess` — standard reCAPTCHA v3 (no proxy)
- `ReCaptchaV3EnterpriseToken` — reCAPTCHA v3 Enterprise
- `ReCaptchaV3EnterpriseTokenProxyLess` — reCAPTCHA v3 Enterprise (no proxy)

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `sitekey` | string | Yes | reCAPTCHA v3 site key |
| `siteurl` | string | Yes | Page URL with the captcha |
| `proxy` | string | Yes (proxy variants) | `http://user:pass@host:port` |
| `user_agent` | string | No | Browser user agent |
| `pageaction` | string | No | The action string for the page |

## Request — Standard

```json
{
  "type": "ReCaptchaV3Token",
  "task": {
    "sitekey": "6LfB5_IbAAAAAMCtsjEHEHKqcB9iQocwwxTiihJu",
    "siteurl": "https://example.com",
    "proxy": "http://user:pass@host:port",
    "pageaction": "login"
  }
}
```
